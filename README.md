## Portfolio

The repository for my personal portfolio, available at [www.liamschenk.ch](https://www.liamschenk.ch). All content is dynamically sourced from **Sanity**, enabling structured and easily maintainable data management.

### Features

- **Dynamic content** powered by Sanity
- **Integrated content editor** via Sanity Studio
- **Media support** for images and videos

### Technologies

- **Next.js** – React framework with server-side rendering
- **Sanity** – Headless CMS
- **Vercel** – Hosting with continuous deployment

> Note: The content is managed via Sanity Studio, hosted directly on Sanity.
